# 梯队实战机会配置簿

男团决赛暴露年轻队员实战密度不足后，训练部门不再凭一张总积分表分配国际比赛机会。本服务把运动员健康许可、技术画像、近期负荷、对手打法类型、搭档组合、赛事级别与报名名额、教练回避关系、培养目标和赛后复盘按版本保存，并在选拔时冻结所采用的数据与政策，给出**可执行阵容**与**可追溯解释**。

## 能力一览

- **版本化事实**：画像、许可（带康复复查时刻）、负荷、主管教练、政策、赛事报名位、复盘全部只追加，按聚合连续版本号保存。
- **冻结决策**：提交方案即冻结数据快照与政策版本；求解器是纯函数，重放同一决定逐位返回原结果。
- **回避审批**：主管日常训练的教练可以提交观察，但不能独自批准自己队员的名额，批准人必须包含非主管教练。
- **阵容约束同时满足**：个人资格（许可 scope、个人负荷上限、退赛生效、证据硬门槛）+ 搭档组合约束 + 全队负荷上限 + 报名位唯一。
- **并发不重位**：两个方案不能重复占用同一报名位；批准基于冻结时的名额版本做乐观并发，落盘整批原子。
- **标识隔离**：相同 `event_id` 内容不同直接冲突隔离；不同赛事即使报名位标识相同也按赛事前缀隔离。
- **释放语义**：退赛/伤病只释放尚未使用（awarded）的名额；既往出场与结果永不被后来评级或复盘覆盖。
- **模拟时钟**：时间只进不退，可推进到报名截止、康复复查、赛事结束；未来生效的退赛在到点时释放名额；重启后待处理决定与里程碑继续可见。
- **解释输出**：为何入选/暂缓（许可、负荷、排序、全局权衡）、一次失利改变了哪些培养缺口、哪些判断证据仍不足。

## 目录

- `contracts/domain.schema.json`：事件信封与按事件类型的载荷字段约定。
- `data/sample.json`：可直接校验的联调样例。
- `src/squad_exposure/`
  - `contracts.py` 契约校验；`store.py` 只追加事件存储（幂等/隔离/乐观并发/原子批写）；`clock.py` 模拟时钟。
  - `state.py` 事件流归约与冻结快照；`selection.py` 确定性约束求解与评分解释。
  - `service.py` 选拔工作流、回避审批、名额占用、释放、重放与待办恢复；`demo.py` 端到端叙事。
- `tests/`：契约与服务语义测试。
- `docs/domain.md`：领域对象、事件与关键语义。

## 测试

```bash
python3 -m unittest discover -s tests
```

## 编译检查

```bash
python3 -m compileall -q src tests
```

## 样例校验

```bash
PYTHONPATH=src python3 -m squad_exposure.cli contracts/domain.schema.json data/sample.json
```

样例有效时输出 `valid`；发现问题时逐行给出字段、代码和中文说明，并返回非零状态。

## 端到端演示

```bash
PYTHONPATH=src python3 -m squad_exposure.cli demo
```

演示覆盖：冻结求解出“对左手克制且实战密度低的年轻队员拿单打、固定搭档拿双打”的阵容 → 主管教练回避与并发名额冲突 → 单打失利后的复盘缺口 → 伤病退赛只释放未使用名额 → 时钟推进到报名截止 → 重放一致与重启恢复。
